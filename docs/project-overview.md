# Project Overview

**Extrackash** is a mobile app that helps individuals track daily expenses, income, savings, and budgets.

**Target users:** students, employees, business owners, freelancers, and anyone managing personal money.

**Goals:** make it easy to record money activity and see where money goes.

**Scope (mini-capstone):** accounts, wallets, categories, income and expenses, transaction history, budgets, savings goals, dashboard. Notifications are the last priority.
